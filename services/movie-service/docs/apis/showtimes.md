# Showtimes API

## Base URL

`/api/showtimes`

---

## Endpoints

### Get all showtimes

GET /api/showtimes

### Get upcoming showtimes

GET /api/showtimes?status=upcoming

### Get showtime by id

GET /api/showtimes/{showtimeId}

### Create a new showtime

POST /api/showtimes

### Update a showtime

PUT /api/showtimes/{showtimeId}

### Delete a showtime

DELETE /api/showtimes/{showtimeId}
